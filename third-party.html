FFmpeg

Files includes parts of FFmpeg: the libavcodec, libavutil and libswresample libraries. They decode audio formats a phone cannot decode on its own, such as the Dolby and DTS sound tracks of many films. FFmpeg is Copyright © 2000–2023 the FFmpeg developers and is licensed under the GNU Lesser General Public License, version 2.1 or later.

The FFmpeg in the app is built from unmodified source with only LGPL components enabled. The build is configured with --disable-gpl --disable-nonfree --disable-version3, so nothing under the GPL or non-free terms is included. The libraries are linked, together with a small wrapper from AndroidX Media3 (ffmpeg_jni.cc, Apache License 2.0), into one library file, libffmpegJNI.so, which the app loads at run time.

Source code

  • FFmpeg 6.0.2 (release/6.0 branch), commit b37bf81a7a9782438e4fe06a249329e279694494: github.com/FFmpeg/FFmpeg (a mirror of https://git.ffmpeg.org/ffmpeg.git). No changes were made to it.
  • Wrapper, CMake file and upstream build script: androidx/media, tag 1.9.0, libraries/decoder_ffmpeg. Used unmodified.
  • The files that make the shipped build, published here: build-ffmpeg-wsl.sh (the developer's script, which adds the three licence flags), build_ffmpeg.sh, ffmpeg_jni.cc, CMakeLists.txt and BUILD-INFO.txt, which lists the exact decoders enabled, the configure options and the NDK used. The app shows the same file under Settings, About, Open source licences ("FFmpeg build details").

Rebuilding libffmpegJNI.so with your own FFmpeg

As the LGPL provides, you can replace the FFmpeg in the app with a modified one. Build a new libffmpegJNI.so and put it in place of the one in the app package for your device's ABI (an APK is a ZIP file; the library is at lib/<abi>/libffmpegJNI.so). The app loads whichever one is there. The steps are those of the upstream module's README:

  1. Check out androidx/media at tag 1.9.0 and the FFmpeg commit above.
  2. Make your changes to FFmpeg.
  3. In libraries/decoder_ffmpeg/src/main/jni, link the FFmpeg checkout as ffmpeg and run build_ffmpeg.sh with the Android NDK (r26b was used), host platform linux-x86_64, minimum API 26, and the decoder list given in the app's build details. Add --disable-gpl --disable-nonfree --disable-version3 to COMMON_OPTIONS in the script to match the shipped build.
  4. Build the module with Gradle (./gradlew :lib-decoder-ffmpeg:assembleRelease); CMake links libffmpegJNI.so from ffmpeg_jni.cc and your libraries.

FFmpeg

يتضمّن تطبيق الملفات أجزاءً من FFmpeg: مكتبات libavcodec وlibavutil وlibswresample. وهي تفكّ ترميز صيغ الصوت التي لا يستطيع الهاتف فكّها بنفسه، مثل مسارات الصوت Dolby وDTS في كثير من الأفلام. حقوق FFmpeg محفوظة © 2000–2023 لمطوّري FFmpeg، وهو مرخّص بموجب رخصة GNU العمومية الصغرى (LGPL)، الإصدار 2.1 أو أحدث.

بُنيت نسخة FFmpeg في التطبيق من المصدر دون تعديل، مع تفعيل مكوّنات LGPL وحدها. ضُبط البناء بالخيارات --disable-gpl --disable-nonfree --disable-version3، فلا يتضمّن شيئًا خاضعًا لرخصة GPL أو لشروط غير حرّة. وتُربط المكتبات، مع غلاف صغير من AndroidX Media3 (الملف ffmpeg_jni.cc، رخصة Apache 2.0)، في ملف مكتبة واحد هو libffmpegJNI.so يحمّله التطبيق عند التشغيل.

إعادة بناء libffmpegJNI.so بنسخة FFmpeg خاصة بك

كما تتيح رخصة LGPL، يمكنك استبدال نسخة FFmpeg في التطبيق بنسخة معدّلة. ابنِ ملف libffmpegJNI.so جديدًا وضعه مكان الموجود في حزمة التطبيق لبنية جهازك (ملف APK هو ملف ZIP، والمكتبة في المسار lib/<abi>/libffmpegJNI.so). يحمّل التطبيق أيّ نسخة يجدها هناك. والخطوات هي خطوات ملف README الخاص بالوحدة الأصلية:

  1. اجلب androidx/media عند الوسم 1.9.0 ونسخة FFmpeg عند الالتزام المذكور أعلاه.
  2. أجرِ تعديلاتك على FFmpeg.
  3. في المجلد libraries/decoder_ffmpeg/src/main/jni، اربط نسخة FFmpeg باسم ffmpeg وشغّل build_ffmpeg.sh مع Android NDK (استُخدم الإصدار r26b)، ومنصّة المضيف linux-x86_64، والحد الأدنى لواجهة API هو 26، وقائمة وحدات فكّ الترميز المذكورة في تفاصيل البناء داخل التطبيق. أضف --disable-gpl --disable-nonfree --disable-version3 إلى COMMON_OPTIONS في السكربت لمطابقة النسخة المنشورة.
  4. ابنِ الوحدة بـ Gradle (./gradlew :lib-decoder-ffmpeg:assembleRelease)؛ فيربط CMake ملف libffmpegJNI.so من ffmpeg_jni.cc ومكتباتك.

عرض مكتوب: إن كنت تفضّل الحصول على نسخة من هذه المواد، أي مصدر FFmpeg الكامل عند الالتزام المذكور أعلاه ومصدر الغلاف وملف CMake وسكربتَي البناء، فراسل haex@gmail.com. يسري هذا العرض ثلاث سنوات على الأقل من تاريخ حصولك على التطبيق، ولا يكلّفك أكثر من تكلفة إرسال النسخة.
