# Files – Privacy Policy

The privacy policy for **Files**, an Android file manager (`com.exception.filemanager`), in English and Arabic.

Published at https://exception3010.github.io/files-privacy-policy/

`third-party.html` (with the files under `third-party/`) is the open source notices page the app's Settings > About > Open source licences points to: the FFmpeg decoders under the LGPL 2.1, the exact source commit, the build scripts and the written source offer.
